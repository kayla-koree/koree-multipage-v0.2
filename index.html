Today's Discovery

괜찮아

gwaen-chan-a · “I'm okay.”

But sometimes… it really doesn't mean that.

  • Same word. Different relationship.
  • Same sentence. Different tone.
  • Same translation. Different feeling.
Context A · a friend asks you along

친구: 같이 갈래?
나: 괜찮아.

→ “No, thanks.”

Context B · a friend checks in

친구: 너 진짜 괜찮아?
나: 괜찮아!

→ “I'm okay. Don't worry.”

Context C · something's clearly wrong

친구: 너 왜 그래?
나: …괜찮아.

→ “I'm really not okay.”

Why Korean is fun

The same words can carry a different weight.

Same words.
Different relationship.
언니 to a close friend's older sister feels warm. To a stranger, the same word can feel forced.
Same sentence.
Different tone.
“너 진짜 괜찮아?” said quickly brushes off worry. Said slowly, it's real concern.
Same translation.
Different feeling.
“괜찮아” translates to “I'm okay” every time — but it doesn't always feel okay.
